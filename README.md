# ספרדית לטיול הגדול

**לומדים מה שצריך לטיול, בתרגולים קצרים וממוקדים.**

אפליקציה לדוברי עברית שרוצים להבין ולענות בספרדית במצבים מעשיים בטיול. Codex כותב ועורך את הקוד ומסביר אותו; דור משתתף בהתקנת הסביבה, בהגדרות ובבדיקות משמעותיות. זו חלוקת העבודה שדור הבהיר ב־15 באוקטובר 2026 כדי ללמוד תוך כדי ולהתקדם ליעד של שבוע, ללא מטלות הקלדת קוד כברירת מחדל. דרך העבודה נמצאת ב־[DEVELOPMENT_GUIDE.md](DEVELOPMENT_GUIDE.md).

## מצב נוכחי

שלב 01 הושלם בהיקף המעודכן: סביבת פיתוח, Git, הרצה באייפון דרך Expo Go ובדיקת הקלטה והשמעה. לאחר שדור ביקש להתקדם בפיתוח במקום לבנות כעת, בדיקת החתימה והבנייה העצמאית נדחתה לתחילת שלב 04, לקראת בדיקת Google ו־Apple. היא עדיין אינה מאומתת. סיכום השלב נמצא ב־[01-environment.json](../.codex-review/stage-handoffs/01-environment.json). שלב 02 מוכן לפתיחה על ידי דור וכולל את היחידה הראשונה ותכנון המסכים ב־Figma.

דור יצר את מאגר הקוד בענף `main` ושמר את הבסיס בקומיט `bdaa41a` עם ההודעה `Add repository foundation`. תבנית Expo והחבילות נמצאות בתוך `mobile/` באותו מאגר. דור שינה את הכיתוב ב־`App.tsx` לשם האפליקציה והסביר מה יוצג; Codex אימת את הקובץ ובדיקת TypeScript עברה. דור הפעיל `npm.cmd start` ודיווח על הרצה מוצלחת באייפון דרך Expo Go.

דור שינה את הרקע לתכלת ואחר כך לוורוד בולט (`#FF00FF`), ודיווח שהשינויים הופיעו רק לאחר Reload ידני אף ש־Fast Refresh מופעל. הסיבה אינה ידועה; דור בחר שלא להתעכב עליה ונמשיך כרגע עם Reload ידני. דור התקין `expo-dev-client` בגרסה 57.0.20 ובדיקת TypeScript עברה. הוא גם הגדיר ב־`app.json` את השם ״ספרדית לטיול הגדול״ ואת ה־slug ‏`spanish-for-the-big-trip`; JSON והתצורה ש־Expo קוראת אומתו. בדיקת השמע הושלמה; הבנייה החתומה וההתקנה העצמאית ייבדקו בשלב 04.

הניסיון הראשון של דור להפעיל EAS init נעצר בגלל קובץ חסר בעותק `indent-string` במטמון הכלי. ניסיון חוזר עם מטמון חדש תחת Windows TEMP הצליח: דור יצר וקישר את [פרויקט Expo](https://expo.dev/accounts/doric2000/projects/spanish-for-the-big-trip). ב־`app.json` אומתו הבעלים `doric2000` והמזהה `eb8d7f0d-b9ba-4e95-9660-836a55a4a43c`. הפקודות הבאות של EAS ימשיכו להשתמש במטמון `SpanishForTrip-eas-20261014` תחת `$env:TEMP`; פרטי ההרצה נמצאים בתכנית וביומן הלמידה. דור יצר גם `eas.json` באמצעות `build:configure --platform ios`; אומת פרופיל `development` עם `developmentClient: true` והפצה `internal`. זו הכנת הגדרות; טרם הופעלה בנייה בענן. אזהרות התלויות של כלי EAS תועדו, וגרסת npm לא שודרגה.

דור התקין `expo-audio`; גרסה 57.0.5 אומתה כתואמת SDK57. לאחר שדור הבהיר את חלוקת העבודה, Codex כתב ב־`App.tsx` את בדיקת ההקלטה וההשמעה, כולל הרשאה, מצב המסך וטיפול בכשלים ובלחיצות חופפות. ב־`app.json` הוגדר נוסח הרשאה בעברית לבנייה משלנו וכובו יכולות שמע ברקע. TypeScript ואריזת JavaScript מקומית ל־iOS עברו, ותצורת ההרשאות אומתה; זו אינה בנייה חתומה. דור אישר שהקלטה והשמעה עובדות באייפון. ההסבר על הקוד והוראות ההרצה נמצאים ב־[מדריך המובייל](mobile/README.md). חשבון Expo נבדק ב־15 באוקטובר: מסלול Free עם 0 מתוך 15 בניות iOS שנוצלו במחזור הנוכחי. יש לרענן את הבדיקה כשנגיע לבנייה בשלב 04. לא נבחר מסלול בתשלום.

בבדיקת התלויות npm דיווח על 22 רשומות של חבילות מושפעות, שמקורן בשלוש התראות עבור `braces`, `node-forge` ו־`uuid`. הדוח נשמר ב־[תיקיית תיעוד העבודה](../.codex-review/npm-audit-2026-10-14.json). ב־15 באוקטובר Codex השלים הערכה סטטית של שלוש ההתראות: התנאים המתוארים בהן לא נמצאו במסלולי הקריאה שנבדקו בתלויות ובתצורה הנוכחיות. הגרסאות המושפעות נשארו; זו אינה בדיקת אבטחה מלאה או אישור לכלי EAS ולשירות הענן. הראיות ומיקום הדוח המנוהל מתועדים ב־[יומן הלמידה](../.codex-review/development-learning-log.json). נבחן שוב שינויי תלויות ותצורה לפני הבנייה. לא הופעל `npm audit fix` או `--force`; הדוח מציע בין היתר ירידה ל־Expo 44 שאינה מתאימה לבסיס SDK57 הנבחר.

הגרסאות שנמצאו גם בקובץ הנעילה וגם בחבילות המקומיות הן Expo ‏57.0.29, React Native ‏0.86.3, React ‏19.2.3 ו־TypeScript ‏6.0.3. תצורת lint לבדיקת כללי קוד עדיין אינה מוגדרת בתבנית זו.

דור דיווח גם על כניסה מוצלחת לחשבונות Apple Developer ו־Expo, מנוי Apple פעיל וגישה ל־Certificates, Identifiers & Profiles, והשלים לפי דיווחו את רישום האייפון ב־Expo. ההרצה ב־Expo Go נבדקה באייפון; חתימה, בנייה בענן והתקנת אפליקציה משלנו ייבדקו בשלב 04. יש לתעד את הצלחת האפליקציה ואת התקדמות הלמידה בנפרד.

בבדיקת השמע הראשונה דור דיווח שההקלטה מופיעה כפעילה, אך אין קול בהשמעה והיא מסתיימת כמעט מיד. ## מבנה המאגר

קובצי הבסיס שנוצרו:

- `AGENTS.md`: הוראות העבודה לסוכנים בשורש Git.
- `DEVELOPMENT_GUIDE.md`: מחזור העבודה והלמידה המשותפת.
- `.gitignore`: כללים לקבצים מקומיים ולתוצרים שאינם נשמרים בהיסטוריית Git.
- `README.md`: נקודת הכניסה לפרויקט.

`mobile/` כבר נוצרה; יתר התיקיות יתווספו כשהשלב הרלוונטי מתחיל:

```text
spanish-for-the-big-trip/
├── mobile/          React Native, Expo ו־TypeScript
├── api/             Node.js ו־NestJS
└── supabase/        שינויי מסד הנתונים ב־SQL
```

דור בחר במבנה השטוח הזה בשלב 01. האפליקציה והשרת יישמרו במאגר אחד, ולכל יישום תהיה התצורה הדרושה לו. את `api/` וקובצי Supabase נקים בשלבים המתאימים. קוד משותף ומערכת לניהול חבילות במאגר ייבחרו רק כשיהיה בהם צורך. `mobile/package-lock.json` נוצר בהתקנה ויישמר ב־Git בסקירת השינוי הבאה, כדי לתעד את הגרסאות שנבחרו.

## היקף הגרסה הראשונה

נבחרו TypeScript, React Native עם Expo, Node.js עם NestJS ו־PostgreSQL ב־Supabase. היעד הוא יחידה 1A מלאה באייפון עם Google ו־Apple לכניסה, שמע בספרדית, תרגול, סימולציה מוכנה, שמירה וחזרה, הקלטה להשמעה עצמית ומפה קטנה. תוכן היחידה והשמע ייבדקו עם דור, שלב אחד בכל פעם. אירוח ה־API ייבחר בשלב הפריסה.
